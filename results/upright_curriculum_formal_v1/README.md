# 正式姿态微调：逐级瞄准课程

从 `wide_translated_full_gain7/ckpt_000001.pt` 的旧瞄准策略开始，使用 SuperMimic 世界模型反向传播微调。不是失败的 v1/v2 权重，也不是展示视频所用的检查点。

本实验没有总训练轮数上限。每累计 100 次实际策略更新进行一次物理评估；未通过则留在当前阶段继续训练。世界模型门槛不通过时，只训练世界模型，不更新策略。数值或程序异常会记录错误并停止，不能冒充训练完成。

## 训练内容

保留原奖励定义和原课程权重调度，增加 Take006 修正第 452 帧的 22 关节软姿态奖励（权重 0.2，尺度 0.35 rad）：双腿、腰、左臂。整个右臂 7 个关节不参与该姿态奖励，由任务学习瞄准。全策略可训练，学习率 1e-6。姿态改善不作为晋级或完成的硬门槛，因此通过任务验收也不等于姿态一定达到人的视觉要求。

阶段 0 是原课程的平衡阶段，瞄准权重为 0；阶段 1 起恢复瞄准奖励，依次训练中心、窄范围、中范围、宽范围、精确瞄准、在线切换目标（阶段 6）。没有固定在某个瞄准课程。

阶段 0 中，回合重置使用修正姿势的概率依次为 0%、10%、25%、50%、100%。每次回合开始随机选旧姿势或修正姿势，不插值关节角。0% 阶段评估旧姿势；后续阶段 0 同时评估两种姿势。阶段 1–6 使用修正姿势评估。每次改变阶段或重置分布，先进行 100 轮世界模型适应，再按模型验证门槛放行策略更新。

## 评估和运行

每次阶段评估使用种子 17、53，要求原固定网格全部通过、随机场景成功率至少 95%，连续 30 秒且不重置。第 6 级通过后，另用种子 101、211 执行完整任务验收（每组 75 个固定、100 个随机场景，5 cm 命中半径和在线目标切换）。两组通过后保存 `accepted.pt` 并结束。

双 GPU 分布式训练，共 512 个仿真环境。控制器服务名为 `upright-curriculum-formal-v1.service`。`runner/` 为固定代码副本，`runner_manifest.json` 校验其身份。控制器有进程锁，支持按 `controller_state.json` 和训练检查点恢复；阶段晋级证据绑定精确检查点哈希。保留最近 5 个训练检查点、各阶段最好结果、晋级检查点与评估报告。

查看状态：`systemctl --user status upright-curriculum-formal-v1.service`。查看 `progress.json`、`train/status.json`、`training.log`。停止：`systemctl --user stop upright-curriculum-formal-v1.service`；停止后重启同一服务会从已保存检查点恢复。关闭 VS Code 不会停止训练。

## 启动验证

21 项针对性测试通过。双 GPU 冒烟训练及恢复验证通过，累计策略更新从 1 延续到 2；测试检查点与正式初始化隔离。`preflight_reference.json` 是正式初始策略在修正重置姿势下的诊断评估，仅用于核对评估链路，不用于晋级。

启动诊断实测：旧策略直接从修正姿势起步，在第 0 级评估中通过 5/101 个场景，随机成功率 5%，未通过。该结果说明不能把修正姿势直接替换后视为能力已经迁移；正式运行仍按旧姿势 → 混合重置 → 修正姿势的顺序推进。正式服务曾启动；当前已按用户要求停止，见下方记录。
