# 站立瞄准课程学习

更新：2026-11-11（Asia/Shanghai）。机器人：`tienkung3_29dof`。本目录记录用户确认的设计，当前交付为文档，瞄准网络和课程尚未实现。

## 1. 目标与已确认决策

天工在自由浮动、原地站立状态下，保持右肩三关节和肘部 pitch 的固定姿态，通过前臂旋转及两个腕关节，让 TCP 指向世界目标。依次学习固定目标、靶面随机位置、不同距离、更小容差、目标切换及移动目标。任务要求指向目标，不要求手部移动到目标位置，也不约束完整手掌朝向。

**最新控制路线：IK 生成监督数据 → 初始化独立末端网络 → 网络直接输出三关节位置目标 → 课程强化学习。** 身体网络负责其余 22 个关节；最终仍是两个网络，不要求合并。课程训练、想象 rollout 和最终推理均不调用 IK，也不使用 `q_IK + Δq` 残差控制。

| 决策 | 已确认内容 |
|---|---|
| 固定姿态 | 右肩 pitch／roll／yaw 为 `(0.20, -0.10, 0.00) rad`，肘 pitch 为 `-π/2` |
| 末端三关节 | 按顺序 `elbow_yaw_r_joint`、`wrist_pitch_r_joint`、`wrist_roll_r_joint` |
| 指向定义 | `right_tcp_link` 原点及局部单位轴 `(0, 0, -1)`；使用实际 FK 状态 |
| 成功容差 | 靶面上的圆形半径；“20 cm”表示半径 `0.20 m` |
| 首个目标 | 初始持臂指向前方约 3 m；静态目标采样后保持世界坐标不变 |
| 难度推进 | 方向范围、距离、精度、速度分别调节；掌握后升级，保留简单任务 |
| 训练基础 | 沿用现有 MuJoCo/mjlab、PD、SuperMimic 与已通过复验的持臂站立策略 |
| 开发规模 | 保留必要接线检查与简短评估，不增加算法横向对比、大范围扫描或完整扰动矩阵 |

## 5. 研究依据

以下只引用原论文或作者教材。课程数值、模型接口及验收条件是本任务的工程设计。

| 来源 | 可借鉴内容与本任务取舍 |
|---|---|
| [Modern Robotics：数值 IK](https://modernrobotics.northwestern.edu/nu-gm-book-resource/6-2-numerical-inverse-kinematics-part-1-of-2/) | 迭代求解思想；这里将任务误差改为指向方向，加入冗余姿态偏好 |
| [Rapid Locomotion via Reinforcement Learning](https://arxiv.org/html/2205.02824v1) | 根据掌握情况扩大命令采样；按方向分区的网格课程留作后续扩展 |
| [Automatic Goal Generation for Reinforcement Learning Agents](https://proceedings.mlr.press/v80/florensa18a/florensa18a.pdf) | 适当难度目标和旧目标复习；首版使用显式采样与计数，不引入 GAN |
| [HOMIE](https://arxiv.org/html/2502.13013v2) | 身体策略逐步适应上肢姿态变化；不照搬其全身姿态范围或训练参数 |
| [HugWBC](https://arxiv.org/html/2502.03206v2) | 上肢接管强度课程及冲突奖励处理；本项目保持已确认的四关节固定约束 |

此前调研中的 [Residual Reinforcement Learning](https://arxiv.org/abs/1812.03201) 解释传统控制叠加学习残差的另一条路线；用户此次选择直接网络输出，因此它不是本方案的执行架构。
