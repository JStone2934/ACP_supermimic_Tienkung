# 方向 IK 教师与单 policy 监督初始化

更新：2026-11-11（Asia/Shanghai）。返回 [入口](README.md)；坐标、动作和奖励见 [设计](design.md)。本流程尚未实现，表中求解及训练参数均为待验证默认值。

## 1. 教师的职责与边界

教师输入实际机器人状态、世界目标和上一实际末端目标，输出一个三关节绝对位置目标 `q_star`。肩肘、腰部和根姿态保持输入状态，只优化已确认的末端三关节。输出关节顺序固定为 `elbow_yaw_r_joint`、`wrist_pitch_r_joint`、`wrist_roll_r_joint`。

教师用于监督数据生成、有限范围的目标可解检查和监督阶段补充标注。网络接管后的课程强化学习、仿真执行、世界模型想象及最终推理均不调用教师；遇到跟踪失败时记录失败，不用 IK 暗中接管。

IK 标签是几何关节目标，不是力矩，也不保证 PD 执行后已达到同样精度。监督初始化学会基本的目标到关节映射，后续强化学习学习实际动力学补偿。

## 2. 方向求解与冗余自由度

令末端候选关节为 `q`，通过完整 FK 得到 `h(q)`、`R_H(q)`，定义：

\[
d(q)=R_H(q)u_H,\quad u(q)=\frac{g-h(q)}{\|g-h(q)\|},\quad r(q)=d(q)-u(q).
\]

每次迭代同时更新 `h(q)` 和 `d(q)`；腕关节会移动 TCP，不能只更新旋转而把手部原点固定。使用 `d-u` 而非仅用叉乘误差，可避免正好反向时叉乘也为零。

以 `q_prev` 表示上一实际下发目标，以 `q_home=(0,0,0)` 表示自然姿态，最小化：

\[
\tfrac12\|r(q)\|^2+\tfrac{w_p}{2}\|q-q_{prev}\|^2+
\tfrac{w_n}{2}\|q-q_{home}\|^2.
\]

`J=∂r/∂q` 包括目标方向随 TCP 平移的变化。阻尼更新为：

\[
\Delta q=-(J^TJ+(\lambda^2+w_p+w_n)I)^{-1}
\left[J^Tr+w_p(q-q_{prev})+w_n(q-q_{home})\right].
\]

实现时使用线性方程求解，不显式求逆。方向任务只有两个独立约束，阻尼和弱姿态偏好用于处理冗余及局部病态。姿态偏好权重必须小于方向目标的实际需求。

| 项目 | 首版默认值／处理 |
|---|---|
| 初值 | 连续序列使用 `q_prev`；序列起点使用实际末端角 |
| 阻尼 λ | `0.01` |
| 连续性权重 wp | `1e-4` |
| 自然姿态权重 wn | `1e-5` |
| 单次迭代增量 | 各关节最大 `0.10 rad` |
| 迭代上限 | 50 次 |
| 回溯 | 步长按 `1、1/2、1/4、1/8` 尝试，目标未下降则停止本次求解 |
| 限位 | 使用与学生动作后处理相同的 `MDP.soft_lo/soft_hi` |
| 有效标签 | 全部有限、不越软限位，且几何角误差 ≤0.25° |
| 求解失败 | 记录原因；可用十倍阻尼从同一连续初值重试一次，仍失败则不生成有效标签 |

单次数值求解失败不等于几何上不可达。首版记录失败集中在哪些目标，并在离线阶段缩小或排除这些区域；不启动全工作空间扫描。允许工程上调整阻尼及弱正则后重新生成带新版本的数据，不能把失败标签直接填成零角。

每个标签还记录到限位的最小余量。贴限样本不进入首批监督集：默认余量小于 1°时仅记录为待复查。该数值是初始数据筛选设置，不是新增的机器人物理限位。

## 3. 数据生成与分支一致性

### 3.1 状态与目标来源

从已通过验收的身体检查点取得标称站立状态，保留真实根姿态、速度、腰部以及肩肘 PD 误差。首批可使用四段 30 秒的标称站立采集；这是后续实施时的数据采集默认规模，本次未运行。

监督目标覆盖静态主线的 `L∈[2,4] m`、`α∈[-15°,15°]`、`β∈[-10°,10°]`，中央和小角度目标适当加密。较宽的几何监督范围不等于直接跳过动力学课程。只有实际标注通过的区域进入初始目标覆盖记录。

生成连续序列，而非只生成互相独立的姿态对。首批默认 256 条、每条 200 帧，50 Hz，总候选约 51,200 帧；序列包含静止目标、平滑位移以及小幅切换，范围不超过上述静态边界。几何数据可以重用不同站立片段，但必须保存来源和序列身份。

优先用冻结的原站立策略＋IK 教师短仿真采集末端运动下的实际状态，所有教师动作也经过同一限位与限速器。这只是监督数据采集，不是最终控制结构。采集若站立失稳，保留失稳记录，失稳后的状态不作为首批正常站立监督样本；这不是课程成功率统计。若使用站立状态加末端姿态的运动学增广，须重新计算 FK、关节历史与速度，并显式标记合成来源，不能称为真实动力学轨迹。

### 3.2 样本内容（拟新增数据格式）

| 字段组 | 保存内容 |
|---|---|
| 身份 | 机器人、关节顺序、模型／配置哈希、状态采集检查点、数据与教师版本 |
| 序列 | `sequence_id`、来源片段、时间索引、重置标记 |
| 状态与历史 | 全身实际状态、学生可见的 10 帧本体历史、上一实际末端 rad 目标 |
| 瞄准条件 | 世界目标、靶面法向、目标世界速度、ρ、σ；与学生输入转换一致 |
| 教师标签 | 限速前的绝对关节解 `q_star`；限速后的执行目标另存 |
| 身体保持标签 | 同一实际观测／原 contact command 下，冻结站立参考策略输出的身体 22 维动作 |
| 质量 | 有效标记、FK 角误差、限位余量、迭代数、求解失败或数据剔除原因 |

教师求解初值和学生输入中的 `q_prev` 都使用上一实际下发的限速后目标。不能用教师内部未执行的上一解作为隐藏条件，否则学生缺少选择同一 IK 分支的信息。`q_star` 是理想位置目标；采集执行时再限速，防止把一次限速增量误当作网络的最终目标语义。

重置后的历史用首帧填充；不能跨回合拼接。无效标签可保留诊断信息，但监督损失必须带有效掩码。丢弃标签的比例和原因单独报告，避免只报有效子集误差而隐藏大量失败。

### 3.3 数据划分

按来源片段和完整目标序列分组后，80% 训练、20% 验证。同一条序列和同一来源窗口不得同时进入两侧。验证目标使用独立随机种子，并包含中心、边缘、近／远位置；不随机拆相邻帧。

另保存少量固定目标用于后续闭环评估。网络拟合和课程升级不得根据这些固定评估目标反复改变目标位置。保留有限、明确的目标覆盖摘要即可，不建立大规模可达性基准。

## 4. 监督训练

学生采用 [设计中的单 actor 权重迁移](design.md#31-首版网络)，复用现有站立网络，扩展目标输入并重新初始化末端三行输出。输入全部来自可在学生运行时取得的量，不输入教师解、教师内部迭代状态或未来目标位置。

令 `s_j=(q_hi_j-q_lo_j)/2` 为软行程半宽，actor 末端三维经固定动作尺度解码后的 rad 目标为 `q_hat`，身体输出为 `a_body`，冻结站立参考输出为 `a_ref`。监督损失为：

\[
L_q=\operatorname{mean}_j[(\hat q_j-q^*_j)/s_j]^2,
\quad L_d=1-d(\hat q)^Tu(\hat q),
\quad L_{body}=\operatorname{mean}_{22}(a_{body}-a_{ref})^2,
\quad L=L_q+L_d+L_{body}.
\]

FK 损失同样更新 TCP 位置，仅替换末端三关节，保留输入的真实肩肘及身体姿态。`L_q` 学习连续的冗余解，`L_d` 保证关节拟合误差与指向一致；`L_body` 在更新共享网络时保留身体动作先验。三个系数初始均为 1，属于待验证默认值。参考策略只提供训练标签，不接管学生执行。参考动作本身不保证新末端姿态下稳定，必须用实际闭环结果检查。

关节拟合损失使用限位前 `q_hat`，避免输出越界后硬裁剪造成拟合梯度为零；FK 损失与执行指标使用软限位后的目标。两者均在限速前比较理想目标，实际动力学误差另行评价。不对有限行程关节使用会跨越限位的任意角度取模。

| 参数 | 首版默认值 |
|---|---|
| 优化器 | Adam，整个单 actor 学习率 `1e-4` |
| batch | 512 个有效样本 |
| 最大训练量 | 50 epochs |
| 梯度裁剪 | norm `1.0` |
| 验证频率 | 每个 epoch |
| 选优 | 先满足身体动作保持门槛，再比较验证指向误差 P95 与关节 RMSE |
| 停止 | 达到监督门槛即保存；未达到时保留最佳，标记监督初始化未通过 |

监督门槛默认：验证集几何指向误差 P95 ≤1°、每个末端关节相对教师目标 RMSE ≤5°、身体 22 维归一化动作相对参考 RMSE ≤0.05，无非有限输出及限位错误。还应报告完整连续序列中的目标跳变量和共享限速器介入比例，用于发现 IK 分支切换或学生输出跳动。动作保持误差不能代替闭环站立验收。

这些是初始化门槛，不是最终 5 cm 瞄准成绩。尤其不能把 `q_hat` 直接代入 FK 的几何误差，当成经过 PD 和自由浮动动力学后的误差。

若验证失败，先检查输入单位、固定轴、教师分支及数据覆盖；需要补数据时，在监督阶段运行学生收集状态，再离线调用教师标注并重新训练。补充监督仍属于初始化阶段，进入课程强化学习后停止调用教师。

## 5. 从监督网络接管到课程

1. 加载监督阶段最佳的完整单 actor 权重，保留原站立 `best.pt` 的冻结副本仅供训练保持损失使用；建立新的 actor 优化器及任务 critic。
2. 用中央 `L=3 m`、半径 20 cm 目标做一次完整自由站立闭环检查。实际身体和末端的 25 维动作都只能来自学生；评估关闭 IK 和站立参考策略，只有四个肩肘目标被固定覆盖。
3. 使用与正式课程相同的观测、动作转换、限速器、PD、历史和 FK 指标，记录三秒捕获、连续至少一秒保持及完整 30 秒身体条件。
4. 通过后按 C1 推进；监督几何门槛通过但动力学闭环未通过时，记录失败并仅在 C1 中央目标进行小学习率适配，不升级范围或精度。监督几何本身不通过时，先补充／修正监督初始化。

离线几何标签不能冒充真实动力学转移；教师控制的物理数据也不能标作“学生控制下的样本”。进入课程后默认重新收集学生动作数据更新世界模型，先进行 500 次仅世界模型适应更新，再开放整个 actor 的策略梯度；旧世界模型作为初始化，不能假定它已经准确覆盖新的腕部动作。

单 actor 开放更新后，站立与瞄准梯度通过世界模型共同优化 25 维有效动作，不切断身体动作或整个 imagined state。冻结的是提供保持标签的参考策略，实际执行的学生仍是一个共享网络；参考损失按 [课程规则](curriculum.md#6-训练更新与身体适配) 逐步退火。

## 6. 保存与交付

监督检查点保存完整单 actor、旧输入归一化与新增显式尺度、输入顺序、历史长度、软限位、动作后处理参数、数据划分及教师／站立参考版本。数据摘要保存候选／有效样本数、各区域覆盖、失败原因、验证误差和模型来源；训练预算完成不等于门槛通过。

拟新增目录见 [入口](README.md#4-开发阶段与交付)。本方案不声明任何尚未实现的数据生成或训练命令可直接运行。最少交付为：一份教师和数据配置、可加载的监督网络、完整验证摘要，以及一次学生独立控制的中央目标轨迹和录像。
