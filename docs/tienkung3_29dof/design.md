# M0–M3 接入设计

## 数据到位前的交付边界

独立模型检查不依赖动作库。合成站立生成真实目标模型的默认姿态、由足底几何解算根高度、50 Hz 常值轨迹和空平地文件，再用同一模型生成接触标签。真实动作泛化、站立控制能力与各训练阶段成功率另行验收。

## 架构

1. `RobotSpec` 统一模型、关节顺序、body/contact frame、PD/effort/velocity/armature/action scale、默认姿态与数据路径。G1 通过适配器保持原行为。
2. 模拟器内部排列与 canonical 排列按名称双向映射；root/torso 均来自配置。
3. 通用 torch FK 遍历所有 body，沿固定链传播位姿/速度，绕 joint anchor 旋转；MuJoCo 为独立数值参照。
4. 接触几何从配置指定 link 提取，只允许累积固定链变换，跨活动关节报错。九类几何必须非空。离线标签与 reward 使用相同模型来源。
5. 维度由关节数推导；兼容 G1 常量仅用于旧调用默认值。机器人身份、模型和执行器哈希、joint order、control_dt 写入新数据与 checkpoint 并校验。
6. 训练、标注、评估与渲染入口逐步显式传递 robot。当前阶段只运行短链路验证，不启动正式训练。

## 数值与集成验收

- 模型：数量/质量/惯量/限位/网格/头部固定；未驱动资产 nu=0，实体 nu=29。
- 随机 1,000 姿态：FK 位置/旋转最大误差 1e-4 m/rad，线角速度 1e-3 m/s、rad/s。
- 有限差分：平滑点 FK/接触梯度 rtol=1e-2、atol=1e-3；包含非零 anchor 与多级固定链的独立小模型。
- 接触距离：表面附近 ±5 cm，与 MuJoCo 对照，P95≤5 mm、max≤15 mm；脚/手单列。未通过时改进几何，不能放宽阈值掩盖差异。
- 合成链路：1/16/64 环境各 500 控制步，检查状态/观测/command/reward/力矩有限；compile/backward、replay、网络前后向与错误元数据拒绝。
- G1：现有数据/标签初始化和短仿真回归，若 checkpoint 可用再做旧权重回归。
