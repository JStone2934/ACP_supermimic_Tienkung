# M0–M3 接入设计

## 数据到位前的交付边界

独立模型检查不依赖动作库。合成站立生成真实目标模型的默认姿态、由足底几何解算根高度、50 Hz 常值轨迹和空平地文件，再用同一模型生成接触标签。真实动作泛化、站立控制能力与各训练阶段成功率另行验收。

## 架构

1. `RobotSpec` 统一模型、关节顺序、body/contact frame、PD/effort/velocity/armature/action scale、默认姿态与数据路径。G1 通过适配器保持原行为。
2. 模拟器内部排列与 canonical 排列按名称双向映射；root/torso 均来自配置。
3. 通用 torch FK 遍历所有 body，沿固定链传播位姿/速度，绕 joint anchor 旋转；MuJoCo 为独立数值参照。
4. 接触几何从配置指定 link 提取，只允许累积固定链变换，跨活动关节报错。九类几何必须非空。离线标签与 reward 使用相同模型来源。
5. 维度由关节数推导；兼容 G1 常量仅用于旧调用默认值。机器人身份、模型和执行器哈希、joint order、control_dt 写入新数据与 checkpoint 并校验。
6. 训练、标注、评估与渲染入口逐步显式传递 robot。当前阶段只运行短链路验证，不启动正式训练。

## 数值与集成验收

- 模型：数量/质量/惯量/限位/网格/头部固定；未驱动资产 nu=0，实体 nu=29。
- 随机 1,000 姿态：FK 位置/旋转最大误差 1e-4 m/rad，线角速度 1e-3 m/s、rad/s。
- 有限差分：平滑点 FK/接触梯度 rtol=1e-2、atol=1e-3；包含非零 anchor 与多级固定链的独立小模型。
- 接触距离：表面附近 ±5 cm，与 MuJoCo 对照，P95≤5 mm、max≤15 mm；脚/手单列。未通过时改进几何，不能放宽阈值掩盖差异。
- 合成链路：1/16/64 环境各 500 控制步，检查状态/观测/command/reward/力矩有限；compile/backward、replay、网络前后向与错误元数据拒绝。
- G1：现有数据/标签初始化和短仿真回归，若 checkpoint 可用再做旧权重回归。

## 证据

所有报告包含版本、种子、实际样本数、模型/配置/数据身份与阈值。设计调整和未通过项写入 progress.md，不能以文件存在代替通过。

## 接触距离修正（实施时发现）

仅使用表面采样点到箱体的最小 SDF，在箱体边角穿入时会低估凸体需要脱离的距离。首轮完整检查中左肘最大误差 22.51 mm，右膝/左右肘/骨盆的 P95 超过 5 mm，未通过；原始失败报告保留在 `evidence/numerics_initial_surface_only.json`。

当前版本在表面点判断存在穿入后，使用凸包面法向、箱体轴以及最多 256 个角度分布的棱边方向与箱体轴的叉积方向的投影区间计算穿入距离；外部分离仍用 8 mm 表面网格。计算保留 torch 梯度，不调用 CPU MuJoCo 参与训练。此算法是经过目标模型数值验证的近似，不声称对任意多面体等价于完整 GJK/EPA（棱边方向经过覆盖采样）。G1 保留原球近似。几何算法版本变为 `convex-surface-8mm-edge-sat-v3`，相应机器人身份、合成动作和标签重新生成。

## 控制周期边界

50 Hz 控制是本次固定契约；RobotSpec 拒绝直接切换其他控制周期，避免历史窗口、目标 horizon 和奖励 dt 混用。物理子步由配置传入，当前为 4（200 Hz）。速度限值用于惩罚和检查，不是 MuJoCo 硬速度约束。

## 兼容性与运行边界

- 无机器人元信息的旧文件仅走 G1 路径，显式天工参数不能覆盖旧 checkpoint 的身份。
- 运行参数只在对应 CLI 进程中绑定，不修改共享 g1 模块常量；库对象持有各自的 RobotSpec。
- 训练流水线的运行目录绑定模型/配置和输入文件哈希；完成标记另绑定命令及文件依赖。输入变化要求新 run-dir，旧标记不会被默认为有效。
- Stage 2/3、重定向后清理与目标到达接口已传递机器人身份，但本交付只验证 M0–M3 和合成站立；不据此宣称这些阶段的天工任务参数或能力已经验收。

原生 CCD 的退化查询也需要检查：当返回零距离、但 witness 点明显分离时，离线求距以 0.1–10 微米的临时几何平移重查原生算法，至少两个非退化结果须在位移误差预算内一致，并立即恢复数据；不能一致时明确报错，避免把退化零值标成真实接触。最小复现参数保存在 evidence/distance_degeneracy.json。仿真求解器未切换为 libccd。

距离退化与上游 [MuJoCo #3383](https://github.com/google-deepmind/mujoco/issues/3383) 描述一致。当前冻结 3.11.0 位于上游修复之前。实验也确认 libccd 在某些分离样本返回错误负距离，因此没有使用该回退；有界重查的附加误差最多 10 微米，远小于 5 mm 验收阈值，且不改变仿真模型或控制状态。

## 最终验收约束

最终数值检查以 `strict_reference=True` 禁用离线标签函数的表面采样回退，独立参照只使用原生 MuJoCo 求距与上述有界退化重查。900 个样本及各类门槛均通过；数值检查不是几何算法在所有姿态/地形的形式证明。

恢复与微调语义分别处理：`--resume` 绑定原数据哈希，`--init` 允许同机器人、同模型与控制配置下使用新数据，从而保留原流水线的数据清理后微调行为。每次新保存的 checkpoint 都记录实际使用的数据哈希。
