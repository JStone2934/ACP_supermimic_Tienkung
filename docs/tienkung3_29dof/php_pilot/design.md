# PHP → 天工 3.0 小批量重定向

2026-11-07，用户授权在 M0–M3 之后，先验证站立、直行、转向、低台阶，结果合格后再考虑攀爬及全部 296 条。起点 `36219b6`，沿用 feat/tienkung3-29dof-acp，保留此前数据和证据。

首批 7 个片段：站立 1、直行 2、左右转向各 1、低台阶 2。源 locomotion 的 vel_cmd 和帧区间用于确认类别；低台阶保留完整片段。只选源 terrain 第 0 个变体，保持原位置/尺寸；不宣称完成其余变体。源文件/片段/地形哈希写入 manifest。

采用 G1 FK 提取语义身体轨迹和足底位姿，按两机器人默认姿态校准参考 frame 和身体比例，再联合优化天工 root 与 29 个关节。足部接触段锚定地形、抑制支撑滑动，约束限位及时间连续性；肘腕通过任务空间目标求解，不直接复制 G1 角度。

独立 MuJoCo 几何质检检查全身地形穿透及默认排除相邻/焊接体后的自碰撞，记录实际排除规则。沿用 M4 门槛：限位误差≤1e-4 rad、穿透最大≤5 mm，超过2 mm持续3帧拒绝；支撑距离P95≤10 mm、足底切向速度P95≤0.05 m/s。失败动作隔离，不自动加入训练集。

跟踪验证分为自由根部的参考 PD 回放（不固定/外力扶持根部）和合格子集上的小规模 ACP Stage 1 训练/评估；报告跌倒、根部/关节误差、饱和与速度超限，保留录像。几何和跟踪失败均是本轮有效诊断结果，不把数值有限当作动作跟踪通过。

小样本只有开发集，不随机切帧宣称泛化；来自同一动作家族的片段/变体须同组。当前样本不足独立家族的80/10/10划分，报告“泛化评估数据不足”。先完成本批验证，未授权自动开始全量或攀爬训练。

## 首轮发现及试验例外

默认姿态的原始凸包模型存在 knee_pitch_{l,r}_link 与 ankle_roll_{l,r}_link 约34 mm内部重叠；严格自碰撞门槛因此未通过。报告同时提供原始自碰撞和单独排除此两对之后的结果。该排除只用于诊断性筛选，不把动作声明为严格M4合格，也不修改资产/仿真模型。

可以对其余几何门槛满足的片段进行明确标记的探索性短训练。导出这类片段必须显式传入 `--allow-baseline-self-overlap`；报告记录例外和导出状态。其余穿透/滑动/超限片段隔离。后续正式数据验收需解决碰撞模型或确认结构性排除，不能沿用本试验例外宣称全身无碰撞。

v1身体轨迹映射出现摆臂碰髋部、摆动脚穿地及速度尖峰；v2首批腿部动作固定天工中立手臂姿态，保留根部/腰部/腿部任务空间重定向，强化最深脚部穿透和速度惩罚。该版本不保留G1摆臂风格，且不适用于手接触攀爬。
