# 站立瞄准开发入口

更新：2026-11-11（Asia/Shanghai）｜分支：`feat/standing-aiming`

目标：天工 3.0 在站立时，右肩保持固定姿态、肘部保持约 90° 弯曲，使用末端三个自由度持续指向一个固定的世界目标点；随后扩展到小范围随机目标。行走和台阶作为后续路线。

**最新控制要求：最终由一个 policy 同时完成身体平衡和末端瞄准。** 沿用肩肘四关节固定要求；同一个网络实际控制身体 22 维和末端 3 维。IK 可用于离线可达性检查或训练示教，最终推理不调用 IK，不采用依赖在线 IK 的残差输出。

**开发原则：先以最少改动跑通站立定点瞄准，再根据实际问题增加学习与验证工作。** 按用户最新要求，首版不安排算法对比、大范围可达性扫描或完整扰动测试。

## 首版交付

1. 明确末端三关节与手部指向轴，采用一个固定持臂姿态。
2. 自由浮动机器人能够保持该姿态站立，并持续指向前方固定目标。
3. 将同一控制流程扩展到小范围随机目标，保存一个可复用的检查点和演示录像。

最终部署一个 actor：读取本体状态及瞄准目标，输出身体与末端动作，统一交给 PD 执行。训练时的 critic、世界模型和可选 IK 示教不属于部署控制器。

初测固定右臂漂移约 11.07 m；本轮微调已将独立加载评估的骨盆最大位移降至 1.92 cm，并通过姿态和脚位验收。[查看录像](../../../results/analysis/standing_aiming_finetune/best.mp4) · [漂移曲线](../../../results/analysis/standing_aiming_finetune/drift_comparison.png)。下一阶段以该权重初始化单 policy 瞄准训练；当前完成的检查点仍是固定右臂站立策略。
