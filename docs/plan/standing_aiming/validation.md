## 当前阶段：持臂原地站立验收

在标称平地、完整自由浮动动力学下连续运行 30 秒，不重置、不施加外力，动作／观测／指令无噪声。
从初始状态计算整段最大骨盆水平位移 ≤0.10 m、左右脚各自最大水平位移 ≤0.05 m；脚位采用模型对应踝部跟踪坐标，与零样本基线保持同一口径。
同时要求不跌倒、最大躯干倾角 ≤15°、右臂 7 个关节各自保持误差 P95 ≤5°。不扣除起步调整段。

以上七关节保持针对已完成的固定持臂站立；进入单 actor 瞄准课程后，只检查肩部三关节和肘 pitch 四个固定关节，末端三关节按指向误差评价。其余身体位移、姿态和完整回合口径继续保留。

`python -m tools.evaluate_standing --ckpt <best.pt> --out <output_stem>` 重新加载后输出完整 JSON／NPZ。
每 500 次迭代运行独立评估环境，按完整站立、位移超限程度、实际漂移大小依次选优；达标后重新加载复验。
固定关节梯度、动作覆盖、静止奖励的恢复方向与归一化冻结由 `python -m tools.test_standing_task` 核对；短训练覆盖更新、保存及加载。

原始 `ckpt_100500.pt` 持臂基线：30 秒未倒、骨盆最大漂移 11.072 m。训练结果不能仅以总奖励上涨或“未跌倒”判断成功。

2026-11-11 正式微调在第 2000 次通过，并完成保存后复验。独立加载最佳权重：30 秒未倒，骨盆最大位移 1.924 cm，左／右脚 1.225／1.822 cm，最大根倾角 2.628°，右臂各关节误差 P95 最大 3.685°。逐次评估和完整结果见 [任务记录](taskmemory.md#7-持臂站立微调实施2026-11-11)。这项结论针对固定持臂站立，未包括后续方向 IK。

## 1. 三步验证

| 步骤 | 做什么 | 最少记录 |
|---|---|---|
| M0：关节与方向 | 预览固定肩部和约 90° 肘部；转动末端三关节；显示 TCP 指向箭头，对准正前方和几个邻近目标 | 最终角度、指向轴、目标范围；是否越限或明显穿插 |
| M1：自由站立单目标 | 完整机器人自由站立，末端持续跟踪同一个世界目标点 | 实际站立时长、跌倒、角误差、身体漂移和肩肘保持误差 |
| M2：随机目标 | 用同一小范围内的几个目标重复运行；稳定后加一次目标切换 | 角误差与保持时长、切换后的重新稳定时间、代表性录像 |

M0 可固定基座看清几何关系；M1、M2 的站立效果必须来自自由浮动动力学。固定基座成功、参考动作回放成功或训练日志数值有限，都不能代替这段实际运行。

按用户最新要求，M1、M2 的最终验收只运行一个 actor，由它输出身体 22 维和末端 3 维；肩肘四维仍保持固定角度。评估关闭 IK／示教接管及训练教师，不接受必须在线调用 IK 才能完成瞄准的检查点。保留已有骨盆 ≤10 cm、每脚 ≤5 cm 的原地约束，新增指向精度指标。

目标点在每回合初始化后保持世界坐标不变。让身体略有自然晃动时，观察末端是否主动补偿；外力推扰、不同地面和载荷等测试后续有需要再加。

### 已完成的定义预览（2026-11-11）

用户观看双视角总览及 16.5 秒视频后确认：固定右肩三关节和肘部 pitch，允许前臂 `elbow_yaw` 与腕部 pitch／roll 转动。视频中三个末端关节分别往返 ±45°，固定角度、指向轴和产物位置见 [计划](plan.md) 与 [资产列表](asset_list.md)。首版沿用该持臂姿态与 TCP 局部 −Z；初始指向朝前略向下约 11.4°。

该预览冻结身体并直接设置关节角，只完成几何定义展示。之后固定持臂站立及保存加载已经完成，见本文当前阶段记录；单 policy 目标跟踪仍待实施。

## 2. 简单指标

设实际指向与目标方向为单位向量 `d`、`d_target`：

```text
theta_deg = acos(clamp(dot(d, d_target), -1, 1)) * 180 / pi
```

方向均按当前实际手部位置和姿态计算。训练可使用平滑的点积误差，评估用角度便于理解。

| 指标 | 首版口径／建议目标 |
|---|---|
| 自由站立时长 | 目标为 30 秒；未达到时记录实际时间和终止原因 |
| 指向误差 | 同时记录真实靶面厘米误差与角误差；按预先固定的捕获后时段统计 P95，容差半径从 20 cm 逐步收紧 |
| 连续保持 | 有效前向交点持续处于容差内；静态依次要求 1、3、5 秒，切换按驻留时间采用 2 秒 |
| 转向稳定时间 | 从目标生效到开始完整保持区间的时间，只有保持完成后才确认，未达到则记失败 |
| 身体漂移／滑脚 | 沿用完整 30 秒骨盆最大水平位移 ≤10 cm、每只脚 ≤5 cm；不能靠挪动身体替代末端指向 |
| 固定姿态误差 | 记录右肩三个关节和肘部 pitch 的实际角度相对指定值的误差 |
| 执行状态 | 出现明显越限、长时间力矩饱和或身体穿插时记录并修正；不要求首轮全量统计分析 |

固定评估的捕获后时段预先规定为第 3–30 秒，并同时报告整段误差和捕获时间；不从轨迹中挑选最好的片段作为唯一成绩。跌倒或对不准的回合也保留结果。

监督准备阶段选定可用目标范围，首轮在该范围内评价。教师求解失败或限位导致不可达时，记录并修订后续采样；课程运行不调用 IK 接管，不在同一回合移动目标制造成功。

## 3. 接入时的一次性核对

实现时顺手完成以下核对即可，不另建大规模测试工程：

- 一个已知姿态下，目标沿指向轴时角误差接近 0°，目标在反方向时接近 180°；关节动作使用正确单位和名字映射。
- 实际执行的 29 维合成动作，与历史动作、replay 和世界模型输入一致；想象步骤也使用同一个固定世界目标和动作组合规则。
- 右臂旧参考奖励已按新任务处理，仿真统计与训练奖励没有一边要求瞄准、另一边要求恢复旧手臂姿态。
- 保存一次当前配置和检查点，再加载并运行同一固定目标，确认能够复现控制流程。完整训练断点恢复测试可在实际需要续训时进行。

这些核对针对具体接线错误；不会因为原有全部机器人测试或全量动作库尚未重跑，就把站立瞄准开发扩展成另一个项目。
