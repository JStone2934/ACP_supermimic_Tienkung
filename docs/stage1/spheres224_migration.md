# 天工 Stage1 切换 224 球

2026-11-10，用户明确接受此前展示的天工 224 球方案，并要求与 G1 保持一致。此决定替代此前“224 球候选尚未推广”的选择状态；历史诊断结果保留。

## 实现与边界

`ContactCfg.contact_geometry="spheres224"` 和训练参数 `--contact_geometry spheres224` 选择该方案。球心与用户查看的 CSV 逐数值一致：左右脚各 28，其余七组各 24，总计 224；全部半径 10 mm。

球到地面/box 的距离、最小值聚合及 sigmoid 接触函数沿用 G1 的计算路径。该模式不生成密集表面点，也不启用天工特有的凸包穿透奖励覆盖分支。初始化仍利用原碰撞凸包顶点生成球心，训练迭代不再进行凸包距离计算。G1 的实际球心、半径、分配保持不变；天工没有复制 G1 每脚 4、每手 48 的布局。

`legacy` 默认模式保持原行为，供旧断点、转换和已有工具使用。机器人原生 MuJoCo 碰撞模型、原动作、地形、接触标签及转换验收没有改变。以后评估和 Stage2 从检查点 `ctc_cfg` 读取新模式。

## 几何与数值验证

- 22 项测试通过：接受图的球心/半径固定哈希、G1 原球体固定哈希、九组归属、距离/接触函数姿态梯度有限差分、恢复几何匹配保护，以及原机器人契约/数据装配/资产缓存测试。证据 `evidence/spheres224_regression.txt`。
- 去掉凸包覆盖分支后重新筛查相同 120 个姿态、1080 次部位检查：仍为 0 次漏判、4 次足部假接触；原生近表面距离误差 P95 约 8.19 mm、最大约 14.75 mm。加权标签奖励差 P95 约 0.002815、最大约 0.004086。证据 `evidence/spheres224_no_hull_probe.json`。
- 这些结果确认实现与已接受方案相符，不表示稀疏几何与原生碰撞距离精确等价，也不代替完整策略仿真验收。
